# Checklist de UI Review

Use este checklist em mudanças de interface e em revisões de screenshots. Marque apenas o que for aplicável à tela alterada.

## Layout

- [ ] Não há overflow horizontal.
- [ ] Nenhum elemento está cortado ou desalinhado.
- [ ] O espaço disponível é usado com equilíbrio, sem stretch artificial.
- [ ] O conteúdo não está excessivamente comprimido.
- [ ] Espaçamentos e alinhamentos seguem os padrões da tela.

## Hierarquia

- [ ] O título principal é identificável.
- [ ] A ação principal é evidente.
- [ ] Ações secundárias estão subordinadas corretamente.
- [ ] Informações técnicas continuam legíveis.
- [ ] Badges e status são compreensíveis.

## Responsividade

- [ ] 1366 × 768 revisado.
- [ ] 1440 × 900 revisado.
- [ ] 1920 × 1080 revisado.
- [ ] 390 × 844 revisado quando aplicável.

## Estados

- [ ] Empty state.
- [ ] Loading state.
- [ ] Error state.
- [ ] Conteúdo mínimo.
- [ ] Conteúdo grande, listas longas e textos extensos quando aplicável.

## Interação e acessibilidade

- [ ] Menus, dialogs e drawers abrem e fecham corretamente.
- [ ] Navegação por teclado e foco visível funcionam.
- [ ] Botões têm nomes acessíveis e estados disabled corretos.
- [ ] Tooltips não são a única forma de comunicar informação essencial.
- [ ] Ações destrutivas mantêm confirmação.

## Classificação

- **P0:** bloqueia o uso ou uma funcionalidade.
- **P1:** problema relevante de UX.
- **P2:** melhoria importante.
- **P3:** refinamento visual.
